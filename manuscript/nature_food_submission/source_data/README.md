Source data for the GMNPS main figures

This directory contains the quantitative source data used for the manuscript
figures in "Personalized calibration transforms nutrient profiling systems for
precision nutrition".

Files:
- `figure2_nps_preservation_metrics.json`: preservation metrics for Fig. 2a.
- `figure2_category_transition_v4.csv`: broad NPS category transitions for Fig. 2b.
- `figure2_3_food_group_summary_v4.csv`: food-group summaries used in Fig. 2c and Fig. 3a,b.
- `figure2_v3_vs_v4_summary.json`: old-mask versus expert-revised-mask comparison for Fig. 2d.
- `figure2_3_food_summary_v4.csv`: food-level summaries used in Fig. 3c,d.
- `figure4_gmrepo_auroc.csv`: GMrepo external plausibility AUROC results for Fig. 4a.
- `figure4_synthetic_benchmark.csv`: digital-gut-twin benchmark results for Fig. 4b.
- `figure4_design_ablation.csv`: design ablation results for Fig. 4c.
- `figure4_delta_cap_sensitivity.csv`: delta-cap sensitivity results for Fig. 4d.

Fig. 1 is a framework schematic. Its bounded-transform panel is generated from
the scoring equation, and its single-food distribution panel is illustrative,
not used as quantitative evidence.
